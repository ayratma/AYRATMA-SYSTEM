# AYRATMA SYSTEM Roadmap

## Phase 1 — Installable shell
- [x] Native Kotlin/Compose project
- [x] Dark dashboard and module placeholders
- [x] GitHub Actions debug APK workflow

## Phase 2 — Local foundation
- [ ] SQLite memory repository
- [ ] User-selected folders through Storage Access Framework
- [ ] Task and approval manager
- [ ] System information using public Android APIs

## Phase 3 — AI
- [ ] CORE orchestration layer
- [ ] ANALYST, ENGINEER, GUARD specialist agents
- [ ] Optional local GGUF model runtime
- [ ] Optional remote provider connection

## Phase 4 — Cloud and intelligence
- [ ] Authenticated cloud API
- [ ] Web research with source tracking
- [ ] Knowledge base and retrieval
- [ ] Agent factory with permission boundaries

## Safety requirements
Sensitive file changes, code execution, server operations, updates, external account actions, and spending require explicit user approval. Use sandboxing, allowlists, backups, rollback, and audit logs. Android background execution is subject to OS limits.
